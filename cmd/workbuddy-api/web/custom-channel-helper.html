自定义渠道配置生成器

在你的电脑上把配置填好 → 复制一段 JSON → 粘到飞牛面板「＋ 自定义渠道 → 从 JSON 导入」。网关在飞牛上，所以模型列表要在飞牛面板里点「拉取模型」自动取，这里填的只是备用。

  1. 选平台
  2. 填 api_key
  3. 选/填模型
  4. 复制配置
  5. 粘到飞牛面板

① 你要接哪个平台？

选不到你的平台？选最后一项「其他 / 自建」，自己填 base_url 即可——只要它提供 POST {base_url}/chat/completions 就行。

② api_key

key 只存在这个网页里（内存），不会上传到任何地方——这个文件本身不发网络请求。无鉴权的本地服务（Ollama/LM Studio）留空即可。

③ 模型 id

这里的候选项只是**常见示例**，各平台会随时增删模型。最准的做法：粘到飞牛面板后点「拉取模型」，它会真的向对端 /models 取一次列表。

④ 名称与倍率

rate：0 = 免费/最便宜，自动选渠时优先；正数 = 按倍率从低到高；负数 = 未知，排最后。你自己买的付费 key 建议填实际倍率（比如官方 1.0），这样自动选渠会优先用免费渠道。

⑤ 复制这段配置

常见问题

    
为什么这个工具不能直接「拉取模型」？
      
因为它是纯本地网页：浏览器访问别的域名时会被 CORS 拦掉（大多数 AI 平台不允许网页跨域调它们的接口）。所以拉取模型这件事交给飞牛上的网关做——它没有 CORS 限制，面板里的「拉取模型」就是干这个的。

    

    
为什么保存后要重启网关？
      
自定义渠道的运行时是在网关启动时按配置装配出来的（每个实例对应池里一个虚拟账号）。改动配置需要重启一次才能生效。重启后可以在「账号管理」看到这个渠道的虚拟账号（带 🔒，不可删除/停用——删除请回「＋ 自定义渠道」弹层里操作）。

    

    
加进来之后，客户端怎么调用？
      
模型名写成 customopenai/<模型id>，例如 customopenai/deepseek-chat。/v1/models 会把这些名字带倍率后缀一起列出来，直接复制即可。

    

    
多个渠道之间怎么选？
      
同一次请求只会走一个账号。多个自定义渠道都声明了同一个模型时，由挑号策略决定（默认"临期优先"，自定义账号额度都是 0，实际按名称排序）；不同模型则按你配的模型集精确匹配，不会串到别的上游。

    

    
能接「豆包工作」「通义 App」这类客户端吗？
      
不能直接接——它们没有开放 API。要接豆包模型请用「火山方舟」（官方 API）；要接网页版逆向项目（如 webai2api 类）也行，只要那个项目对外暴露了 OpenAI 兼容端点，把它的地址填进 base_url 即可。
